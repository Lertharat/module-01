Познакомился с основными понятиями какими как:

Commit — снимок изменений с сообщением и уникальным хешем.

Branch — отдельная ветка разработки (по умолчанию main/master).

HEAD — указатель на текущий коммит/ветку.

Working directory / Staging area / Repository — три области: рабочая папка, индекс (подготовленные изменения), история коммитов.

Базовый цикл работы:

git init / git clone — создать или склонировать репозиторий.

git status — посмотреть состояние файлов.

git add  — добавить в индекс.

git commit -m "сообщение" — зафиксировать изменения.

git push / git pull — отправить/забрать изменения с удалённого репозитория.

Ветвление и слияние:

git branch  — создать ветку, git switch — переключиться.

git merge  — слить изменения.

git log — история коммитов.

Откат и исправления:

git restore — вернуть файл, git reset — отменить коммиты/индекс, git revert — создать обратный коммит.

.gitignore — список файлов, не отслеживаемых Git.
